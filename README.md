# 应用宝后台积分任务

适用于应用宝 `com.tencent.android.qqdownloader` 的 LSPosed 模块。控制界面会在受信任的隐藏显示中启动应用宝，串行完成当前可领取的两组视频任务。广告由应用宝实际加载和播放；模块在真实奖励回调后关闭广告并等待应用宝确认积分到账，再继续下一条。模块不会伪造观看时长、奖励回调或完成请求。

## 安装与作用域

1. 安装发布页的 APK，在 LSPosed 中启用模块。
2. 勾选模块推荐的两个作用域：**系统框架**（`android`）和 **应用宝**（`com.tencent.android.qqdownloader`）。APK 的 `xposedscope` 元数据包含这两个包名。
3. 重启手机，然后在模块应用中点击“开始后台批量观看”。不需要预先打开应用宝；应用宝账号需已登录。

也可以在模块应用中开启“每天定时后台观看”并选择本地时间。默认关闭；启用后每天重新登记下一次闹钟，重启或系统时间变化后重新计算。定时触发会从后台唤醒应用宝，不要求提前打开控制界面。系统可能将闹钟延后数十秒；如果设备不允许精确闹钟，还可能有更长延迟。

旧测试包 `com.codex.yybpoints` 与本发布包 `io.github.ahdaolma.yybpoints` 是两个不同应用。迁移时先在旧包内停止后台播放并确认隐藏显示已释放，再于 LSPosed 中停用旧包、卸载旧包，启用新包并重启。卸载前可使用应用内的“清理并卸载模块”；系统卸载会删除模块私有数据。

## 功能

- 同时检查滑动视频与白卡视频两组任务，**串行**播放有资格领取的任务。应用宝广告管理器一次只接受一条广告。
- 检测真实奖励回调后尝试关闭广告；有“再看一条”弹窗时使用应用宝原生动作继续。播放期间阻止批量任务重复启动。
- 控制界面显示当前账号、头像、本轮任务和已核对积分。每条任务的到账金额优先读取应用宝领取成功回执中的 `receivedPoint`；未登录时提示登录，金额无法核对的记录不计入合计。
- 本轮有领奖记录时，在自然结束或手动停止后显示开始至结束的日期时间、总积分和按金额汇总；已核对的逐条积分可展开查看。0 条任务不生成总结。
- 有领奖记录的定时与手动运行都会保留最近 14 轮历史总结，包含每条已核对积分。定时任务可单独关闭开始/结束提示；提示经系统框架钩子发送到手机主屏幕，不显示在隐藏显示。
- 后台任务运行时，在应用宝进程内拦截其音频焦点请求并将其播放音量设为零，避免系统音量被改变。停止时释放隐藏显示并结束应用宝进程。
- 后台批量观看期间抑制应用宝进程的系统 Toast，避免提示文字显示在手机主屏幕；任务状态仍显示在模块控制界面。
- 定时运行有 42 分钟上限；系统框架中的隐藏显示另有 45 分钟到期清理保护。正常完成、手动停止、任务页加载失败时都会尝试移除隐藏显示并结束应用宝进程。系统进程异常或手机重启时，Android 自身会释放虚拟显示；极端情况下仍需下次连接真机核对。
- 仅对应用宝已经明确返回失败的领取请求提供补领入口；成功或状态不明的请求不重复提交。

应用内“清理并卸载模块”会在无需清理后台会话时直接打开 Android 系统卸载确认页；有会话时先请求停止，再打开确认页。若系统未确认清理，控制界面会提示重启手机。确认卸载后，模块私有数据由 Android 删除。已有应用宝任务栈无法迁移时，模块会结束旧进程并在隐藏显示重新启动应用宝。

## 性能与验证范围

发布包不安装协议和网络诊断钩子；这些钩子仅供调试包排查问题。头像先读取图片尺寸并采样解码，再生成 128×128 圆形头像。隐藏显示为 180×320 像素，使用两个图像缓冲区。

2026-09-28 在一台真机的**空闲状态**测得旧调试包控制进程约 23 MB PSS，处于系统可回收的缓存空进程；应用宝主进程及两个子进程合计约 424 MB PSS。此数据不是新发布包或广告播放时的内存峰值，不应据此声称内存下降了某个数值。

在应用宝 9.1.4 和同一真机上验证过隐藏显示创建、应用宝启动、两组任务识别、真实奖励回调与到账、连续观看、结束清理。音频隔离通过隐藏显示内的焦点请求探针验证。已从该版本动态任务包确认成功领取回执中 `y.l0.c.a` 是任务页采用的 `receivedPoint`，并通过独立解析测试。2026-09-28 用 ADB 真机复测：已打开的应用宝主任务栈可迁移到隐藏显示；两组任务均为 `canReceive:0` 时，本轮 0 条不生成总结，结束后隐藏显示和应用宝进程均清理；应用内卸载按钮可打开正确包名的系统卸载确认页。首次定时验证时，闹钟在控制页关闭后触发并创建隐藏显示，但冷启动的应用宝任务页未在旧等待时间内加载；随后正常移除了隐藏显示并结束应用宝进程。本地候选版已延长等待时间并改走主屏幕系统提示，**尚未连接真机验证这些修正，也未发布该候选版**。真实广告下的定时任务、逐条金额与历史总结仍需复测。

## 构建

使用 JDK 17、Android SDK 34 和 Gradle wrapper：

```powershell
.\gradlew.bat assembleDebug
```

正式包使用 `tools/build-release.ps1`。脚本从当前 Windows 用户的 `.android/yybpoints-ahdaolma-signing.json` 读取签名配置，私钥和密码均不在仓库中。保管好签名密钥及密码；后续同包名更新必须使用同一密钥。

诊断日志：`adb logcat -s YybPointsProbe:I YYBBackground:I`。调试包有受 `android.permission.DUMP` 保护的 ADB 诊断入口；发布包不含该入口。
